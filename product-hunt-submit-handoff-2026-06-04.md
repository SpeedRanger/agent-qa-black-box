## Description

Agent QA Black Box turns a failed AI coding/session run into a concrete
prevention packet: likely failure modes, required checks, guardrails, rollback
notes, and the next prompt.

It is built for developers and AI-heavy builders who use Codex, Claude Code,
Cursor, and other coding agents, but hate when runs look done while skipping
verification or changing the wrong surface.

## Maker Comment

Coding agents are getting strong enough that the new problem is not "can they
change files?" The problem is whether the run proved the right thing, avoided
adjacent damage, and left a regression check behind.

Agent QA Black Box is the after-action layer for failed agent work. Paste a
public or redacted transcript, error, or diff summary and it writes the
regression pack: likely failure modes, required checks, guardrails, rollback
notes, and the next prompt.

The first paid wedge is five `$19` public/redacted agent-run autopsy slots. The
first `$10` revenue target is real only when receipt/export/invoice evidence
exists.
